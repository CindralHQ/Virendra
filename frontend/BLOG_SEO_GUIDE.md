# Blog SEO Guide

Use this workflow every time you add a new article to `/src/data/blogPosts.js`.

## Simple process

1. Pick one primary keyword with buying intent.
2. Add 3 to 5 secondary keywords that mean nearly the same thing.
3. Write a title that starts with or strongly includes the primary keyword.
4. Write a meta description around 140 to 160 characters with the primary keyword once.
5. Open with a direct answer to the search intent in the first 2 paragraphs.
6. Use 3 to 5 `H2` sections that expand the topic with practical detail.
7. Add 2 FAQ entries using real buyer questions.
8. Add 2 internal links:
   one to the most relevant product/category page
   one to `/contact`

## Blog object checklist

- `slug`: short, lowercase, hyphenated, includes the main keyword
- `title`: clear commercial topic, no vague clickbait
- `description`: ranking-focused summary for search results
- `targetKeyword`: exactly one primary keyword
- `secondaryKeywords`: close variants and long-tail phrases
- `sections`: practical paragraphs and bullets
- `faq`: search-friendly question and answer pairs
- `relatedLinks`: internal SEO links

## Easy keyword formula

Use combinations like:

- `[product/service] manufacturer India`
- `[product/service] supplier India`
- `[service] company India`
- `[product/service] manufacturer Navi Mumbai`
- `[product/service] manufacturer Maharashtra`
- `how to choose [product/service] manufacturer`
- `[product/service] sourcing guide`
